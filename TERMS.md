## 1. Description of Service

**YNAB Sync for Google Sheets™** is a Google Workspace Editor Add-on that allows users to synchronize transaction data between Google Sheets™ and their YNAB® (You Need A Budget) accounts using the official YNAB REST API.

The Add-on runs client-side within the user's Google account via Google Apps Script. It does not run intermediate proxy servers or store your financial data on external servers.
