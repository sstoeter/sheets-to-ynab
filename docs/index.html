About the Application

YNAB Sync for Google Sheets™ is an open and transparent Google Workspace Editor Add-on designed to bridge Google Sheets™ and your YNAB® accounts without intermediate third-party servers.

Client-Side Architecture

Runs securely inside your Google Apps Script runtime. Your financial data is sent straight to YNAB's API, never to any external database.

OAuth 2.0 Security

Standardized Authorization Code Grant with automatic refresh tokens stored securely in Google's protected UserProperties.

Smart Matching

1-to-1 consumption pool matching accurately distinguishes transactions even when identical amounts occur on the same date.

Formula Friendly

Safely handles dynamic formulas (FILTER, ARRAYFORMULA) without corrupting formula expressions or status tracking.
